# Channel Configuration

## How to Change Channel

To update the channel everywhere, run:

```powershell
.\scripts\utils\update-channel.ps1 -NewChannel "your-new-channel"
```

This updates the central configuration file, and all scripts will use the new channel automatically.

## Channel Source

The channel is stored in: `scripts/config/channel-config.ps1`

All scripts and documentation reference this single source.

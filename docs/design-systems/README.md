# Design Systems Documentation

Documentation for design systems extracted from Figma master files.

## Available Design Systems

- **[Checkout Design System](checkout/)** - Checkout flow components and styles

## Purpose

This directory contains comprehensive documentation extracted from Figma design system master files. Each design system has its own folder with:

- Component catalogs
- Style guides
- Structure documentation
- Usage examples

## Adding New Design Systems

1. Create a new folder: `docs/design-systems/{system-name}/`
2. Follow the structure:
   - `README.md` - Overview
   - `components.md` - Component catalog
   - `styles.md` - Style guide
   - `structure.md` - Structure documentation
   - `usage-examples.md` - Usage patterns

3. Update this README with the new system

## Documentation Standards

- Use consistent templates across all design systems
- Include node IDs for reference
- Document relationships between components
- Provide usage guidelines
- Update when design systems change
